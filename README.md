# Shorted
Simple self-hostable URL shortener

#Getting Started

**Prerequisites**
- Docker and Docker Compose installed

**Setup**
1. Clone the repository:
bash
   git clone https://github.com/MrSplatchy/Shorted.git
   cd Shorted

2. Build and start all services:
bash
    docker compose up --build

3. Once running, the app is available through Nginx:
   http://localhost:80
